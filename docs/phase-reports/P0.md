## Security/privacy review

Only synthetic data is displayed; no production account, personal-data collection or email delivery exists. Preview state is in memory and resets on refresh. Local database password is generated and ignored by Git. API does not expose real data or accept business mutations. Backup/telemetry operations are deferred per the user's scope; future domain audit requirements remain documented.

## Known limitations / risks

This is P0, not the completed MVP. Authentication, persistence, RLS, registration, verified guardianship, valid fixture lifecycle/deadlines and real email are future phases. UI role switching is not a security boundary. Preview dates are fixed November 2026; preview actions do not enforce business deadlines. No backup/restore, centralised logs, monitoring, cloud publication or production readiness is claimed. See OPEN_ISSUES.md.
